# Project lifecycle

States: INTAKE -> OUTLINE_DRAFT -> WAITING_FOR_APPROVAL -> APPROVED -> IMPLEMENTING -> REVIEWING -> VERIFIED -> PACKAGED.

Similarity red sets the project to BLOCKED. Mức đỏ bị chặn tuyệt đối; phải thay đổi phạm vi rồi kiểm tra lại.

Approval là xác nhận trong chat của người quản lý. Agent ghi nhận vào project.yaml, không yêu cầu file approval riêng.

Thay đổi lớn phải cập nhật outline, requirements, timeline, test plan, tài liệu liên quan và approval state trước khi code tiếp.
