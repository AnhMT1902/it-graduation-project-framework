# Thesis Implementation

Run only after APPROVED and after the architecture is usable.

- Implement requirements and acceptance criteria.
- Add suitable tests for every feature.
- Update migrations, DBML, API docs, and user docs when behavior changes.
- Never expand scope silently; create a scope-change request.
- Keep implementation at graduation MVP depth; do not add production-scale infrastructure or advanced integrations without explicit scope approval.
- Do not depend on host runtimes beyond Docker Desktop, Docker Engine, and Compose.
