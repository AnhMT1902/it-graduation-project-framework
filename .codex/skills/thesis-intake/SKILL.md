# Thesis Intake

Input may be free text, a document, YAML, or JSON. The user is not required to follow a fixed input schema.

1. Extract student, title, problem, users, features, contribution, and requested documents.
2. Preserve uncertainty as questions; never invent requirements.
3. Create or update the normalized project.yaml.
4. Create a folder directly under projects using the web-app template.
5. Move to OUTLINE_DRAFT only when the minimum profile is complete.
